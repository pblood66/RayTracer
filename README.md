# 3D Ray Tracing Engine

Simple proof of concept 3D ray tracing render engine written in Java. 

Personal project to learn more about rendering images and ray tracing. Custom built 3D render engine that produces ppm files. Room to add more in the future. Has 1 object type (spheres) that can have custom materials that interact differently with rays. 

## Materials Implemented
- Diffuse Materials (Lambertian Reflections)
- Metal (Reflective surfaces)
- Transparent (Dielectric)
